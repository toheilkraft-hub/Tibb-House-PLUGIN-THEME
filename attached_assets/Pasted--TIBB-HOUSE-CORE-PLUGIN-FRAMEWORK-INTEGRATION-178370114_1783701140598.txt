====================================================

TIBB HOUSE CORE PLUGIN FRAMEWORK INTEGRATION

IMPORTANT:

The theme is being developed separately from the existing
"Tibb House Core" plugin.

The plugin is the content management system.

The theme is the presentation framework.

DO NOT modify, recreate, duplicate, or replace the plugin.

The theme must respect the existing plugin architecture.

The plugin already controls:

• Custom Post Types
• Custom Taxonomies
• Custom Fields
• Meta Data
• Relationships
• Admin Dashboard Sections
• Content Organization

The theme must only retrieve and display this information.

====================================================

CONTENT TO DESIGN CONNECTION

The theme must automatically understand every content section created by the plugin.

Example:

In WordPress Dashboard:

Treatments
    ↓
    Add New Treatment

Admin enters:

Treatment Name:
Hijama

Overview:
(text)

Constitutional Type:
(text/data)

Vital Areas:
(text/data)

Evidence Level:
(text/data)

Research:
(text/data)

Remedies:
(text/data)

Conditions:
(related entries)

After publishing:

The theme automatically generates the Treatment page.

No manual page creation.

No manual block insertion.

No Elementor editing.

====================================================

SECTION VISIBILITY LOGIC

The theme should intelligently control sections.

If plugin data exists:

Display the section.

If plugin data does not exist:

Hide the section completely.

Example:

Treatment has:

Evidence Level ✔

Research ✔

Remedies ✖

Output:

Evidence section visible.

Research section visible.

Remedies section hidden.

The design should automatically adapt based on available content.

====================================================

ADMIN EXPERIENCE

The administrator should only manage content from WordPress Dashboard.

The workflow:

1. Open Treatment section.
2. Add information.
3. Publish.
4. Website automatically updates.

The administrator should never edit theme files or manually design pages.
